# AttendX Test Scripts

This repository contains basic test scripts for the AttendX
student attendance application.

## Files

### login_test.py
Tests login inputs, including valid details, empty fields
and a missing username.

### attendance_test.py
Tests attendance details for Present and Absent status
and checks an invalid attendance status.

## Requirements

- Python 3
- Git
- Visual Studio Code

## How to Run

Open the terminal in VS Code and run:

```bash
python login_test.py
python attendance_test.py
